## 6. Studio CMS & Data Architecture
- **Route**: Accessible at `/studio`.
- **Owner Authentication**: Managed via Supabase Auth.
  - Owner Email: `oluwaseyidavid406@gmail.com`
  - Access is restricted via `RequireOwnerAuth.tsx` and Supabase Row Level Security (RLS).
- **Database Tables**:
  - `portfolio_projects`: Stores both AI Automation (`AI_AUTOMATION`) and Web Design (`WEB_DEVELOPMENT`) projects.
    - Fields: `id`, `title`, `slug` (globally unique), `category`, `status` (`DRAFT` / `PUBLISHED` / `ARCHIVED`), `sort_order`, `core_challenge`, `solution_delivered`, `short_description`, `project_url`, `technologies`, `featured`.
  - `portfolio_project_images`: Storage paths, public URLs, captions, alt text, and display order.
  - `portfolio_inquiries`: Contact form submissions, timestamps, and webhook delivery status.
- **Storage Bucket**:
  - `portfolio-media`: Public bucket for project screenshots and workflow diagrams.
  - Uploads are automatically downscaled (max 2048px) and converted to optimized WebP in-browser before upload (`imageOptimization.ts`).
- **URL Slug Rules**:
  - Every project must have a unique slug across the database.
  - `ProjectEditorModal.tsx` provides live debounced uniqueness checks and auto-suggests alternative slugs (e.g. `voltedge-accessories-website` or `-2`) if a collision occurs.

## 7. Contact Form & n8n Webhook Architecture
- **Submission Flow**:
  1. Visitor submits name, email, and message in `Contact.tsx`.
  2. `submitInquiry()` in `src/lib/supabase.ts` calls the Supabase function `portfolio_submit_inquiry` (validation, sanitising, escalating rate limits) which saves the record to `portfolio_inquiries`, so data is never lost.
  3. The browser then sends only the new inquiry id to the n8n webhook; n8n claims the real data from the database (`portfolio_claim_inquiry`) before sending any email:
     - Production endpoint: your n8n webhook (kept in `.env` as `VITE_N8N_WEBHOOK_URL`, never committed)
     - Proxy rewrite path: `/api/n8n/portfolio-request` (configured in `vite.config.ts` and `vercel.json` to prevent CORS issues).
  4. Webhook delivery outcome (`OK` or error) is saved back to the inquiry database record.
- **Confirmation Message**:
  - *"Thank you for reaching out, I will be in touch shortly."*

## 8. Verification & Development Commands
Always run and verify these commands before committing code:
```bash
# Start local development server
npm run dev

# Run TypeScript type check (must have 0 errors)
npx tsc --noEmit

# Build production bundle
npm run build

# Preview production build locally
npm run preview
```

### Sandbox Execution Note (Windows)
When running `npm run build` or git commands on Windows within agent sandboxes, transient `EPERM` or filesystem lock errors may occur with Rollup/Vite. Running the command unsandboxed (`BypassSandbox: true`) bypasses this issue.
